# VIVISION-MAS

多角度测色仪上位机系统仓库，当前包含 1.0 原型主链路、WPF 主界面、SQLite 本地数据层、模拟仪器运行时、报告导出、历史追溯，以及基于参考截图持续重构中的桌面 UI。

## 当前状态

1. `MAS_V1.sln` 可编译。
2. `MAS.WinUI` 可启动，主程序为 WPF 桌面程序。
3. `MAS.Tools` 可运行，用于命令行验证建库、测量、报告导出等主流程。
4. 已接入 GitHub 远程仓库，适合在新的 ChatGPT 账号或新的本地环境中继续开发。

## 项目结构

1. `MAS.Core`
   领域实体与枚举，包含仪器、样品、标准样、容差模板、测量任务、测量记录、角度结果、效果结果、原始报文等核心对象。
2. `MAS.Application`
   应用层接口与服务，包含任务、测量流程等业务服务。
3. `MAS.Infrastructure`
   SQLite 数据访问、配置、报告导出、数据维护、仪器运行时装配等基础设施实现。
4. `MAS.WinUI`
   WPF 上位机界面。
5. `MAS.Tools`
   命令行验证工具，用于跑最小业务闭环。
6. `UI改进需求`
   用户提供的 UI 参考截图和生成的示意图，作为持续重构界面的依据。

## 快速启动

1. 打开 `MAS_V1.sln`
2. 将启动项目设置为 `MAS.WinUI`
3. 直接运行，或构建后启动：
   `MAS.WinUI/bin/Debug/net8.0-windows/MAS.WinUI.exe`

命令行验证工具：
`MAS.Tools/bin/Debug/net8.0/MAS.Tools.exe`
